# RJSXRD White / Bypass — собственная автообновляемая подписка

Скрипт скачивает `bypass-all.txt` и оставляет **только** узлы, в *названии* которых есть слова вроде `white`, `white list`, `whitelist`, `bypass`, `обход`, `белые`, `белых`, `белый`, `вайтлист`, `разблокировка`.

Поле названия — это `#` в VLESS/Trojan/SS ссылках или `ps` в VMess JSON. Фильтр **не ищет** слова в IP, URL, SNI или параметрах. Ссылки не преобразуются и не модифицируются. Точное совпадение параметров может важнее названия.

## Быстрый запуск без VPS (через GitHub)

1. Создай **новый публичный репозиторий** GitHub, например `my-white-vpn`.
2. Распакуй этот архив и загрузи **содержимое** папки `rjsxrd-white-filter` в **корень** нового репозитория. Должна сохраниться директория `.github/workflows/update.yml` (скрытая папка!).
3. В GitHub открой `Actions` → разреши workflows при необходимости → `Update White/Bypass subscription` → `Run workflow`.
4. Если выполнение закончилось успешно, проверь, что создался файл `subscriptions/white-bypass.txt` с конфигурациями.
5. Твоя внешняя подписка:

   `https://raw.githubusercontent.com/ТВОЙ_ЛОГИН/my-white-vpn/main/subscriptions/white-bypass.txt`

   Заменяй `ТВОЙ_ЛОГИН`, название репозитория и ветку (`main`) своими реальными значениями.
6. В **3x-ui → Клиенты → карточка клиента → Внешние подписки**, добавь ссылку с типом `subscription` и включи `Enabled`. Обнови подписку в Happ.

Расписание: раз в час (`17`-я минута) плюс ручной `Run workflow`. GitHub не гарантирует точность времени запуска; выполнение может задерживаться. Обновление файла не мгновенно обновляет Happ: клиенту нужно обновить свою подписку.

## Права и типичные ошибки

- Workflow использует `permissions: contents: write`. Если `git push` возвращает `403`, проверь GitHub **Settings → Actions → General → Workflow permissions**, ограничения организации, правила защиты ветки. При необходимости разреши GitHub Actions запись в репозиторий.
- Scheduled workflows исполняются в ветке по умолчанию и могут отключаться GitHub при длительной неактивности репозитория.
- Репозиторий должен быть **публичным**, чтобы сырой файл был доступен обычной ссылкой из Happ/3x-ui без авторизации.
- Если upstream недоступен или совпадений нет, скрипт завершится с ошибкой **без перезаписи прошлого результата**. Это оставит старые конфигурации; следи за workflow, особенно если нужны гарантии свежести.
- `#profile-update-interval: 1` — метаданные подписки, не гарантия фактического обновления клиента каждый час.

## Проверить локально

Python 3.10+; сторонние библиотеки не требуются.

```bash
python3 -m unittest discover -s tests -v
python3 filter.py
# Для локального готового файла:
python3 filter.py --input bypass-all.txt --output subscriptions/white-bypass.txt
```

Чтобы изменить слова поиска, отредактируй `NAME_PATTERN` в файле `filter.py`. Поддерживаются VLESS, VMess, Trojan, Shadowsocks и несколько других распространённых share-link форматов.

## Важные ограничения

- Совпадение по имени **не доказывает**, что сервер обходит белые списки или работает в конкретной сети. Проверяй вручную.
- Узлы принадлежат третьим лицам; неизвестны их политика логирования, права коммерческого использования и стабильность.
- Выключение внешней подписки в 3x-ui прекращает **выдачу** списка, но **не отзывает ранее полученные ключи** на чужих серверах.
- Не отправляй через такие серверы конфиденциальные данные без понимания рисков и не обещай клиентам надёжность или приватность чужих узлов.
